# Licence

Business Source License 1.1.

Reading the code, running it to evaluate it, and auditing it are all free.
Running it in production requires either a subscription from us or a separate
agreement if you're hosting it yourself. Four years after each release, that
release becomes available under Apache 2.0.

This isn't an open source licence and the licence text says so itself. The
correct term is source-available.

## Why this licence

The two obvious alternatives both permit any internal use, and a company running
this system for its own business is internal use, so either one would give away
the exact thing we're selling.

The Business Source License lets the publisher state precisely which production
use is free, and here that's none of it.

## Why publish the source at all

A bank or a ministry can have its own security team read the code before buying
the hosted service, and vendors of closed systems can't offer that.
